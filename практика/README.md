Заказ 04 — мониторинг процессов

Цель работы

Создать программу на Python, которая наблюдает за процессами Windows,
записывает показатели CPU и памяти и сохраняет историю измерений в
CSV-файл.

Используемые файлы

• monitor.py — программа мониторинга процессов.
• worker.py — тестовый процесс. Поддерживает режимы growth и
steady.
• run_workers.py — запускает два тестовых процесса, перезапускает
один из них и завершает тест.
• telemetry_sample.csv — пример готовых измерений.
• process_history.csv — файл с результатами работы монитора.

Установка

Для работы используется библиотека psutil.

python -m pip install psutil

Запуск проверки

1. Открыть папку практической работы в Visual Studio Code.
2. В первом терминале запустить монитор:

python monitor.py --match worker.py --duration 90

3. Сразу открыть второй терминал (Terminal → New Terminal) и
запустить тестовые процессы:

python run_workers.py

4. Дождаться завершения мониторинга. Результаты сохраняются в
process_history.csv.

Что записывается в историю

Монитор сохраняет время измерения, PID процесса, время создания
процесса, уникальный ключ процесса, имя и командную строку, загрузку
CPU, объём занятой памяти RSS и статус измерения.

Результат проверки

Во время теста запускаются два процесса с одинаковым именем. Один из
процессов перезапускается, поэтому получает новый PID. По времени
создания процесса и ключу, составленному с учётом PID, можно отличить
новый экземпляр от завершившегося.

Файл process_history.csv содержит историю измерений. Его можно открыть
в Visual Studio Code или Excel.

Вывод

В ходе практической работы была создана программа мониторинга процессов.
Она собирает показатели использования процессора и оперативной памяти и
сохраняет их в CSV-файл. На тестовых процессах проверено, что после
перезапуска процесс получает новый PID, поэтому его можно отличить от
предыдущего экземпляра.
