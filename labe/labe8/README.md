ЛР 8. Карта памяти

В лабораторной работе изучается использование памяти программами: выделение, запись и освобождение памяти, а также обнаружение утечек по результатам замеров.

Что находится в папке:

  import mmap.py — программа для проверки использования памяти на четырёх этапах.
  le.py — программа для наблюдения за постепенным увеличением памяти.
  screenshots/ — 4 скриншота с выполненными заданиями (заменить заглушки своими снимками).

Проверка

GitHub Actions проверяет, что все заглушки заменены настоящими скриншотами.

Результат находится во вкладке Actions → Проверки.
