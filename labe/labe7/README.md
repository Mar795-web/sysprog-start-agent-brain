ЛР 7. Потоки Python и GIL

В лабораторной работе изучается работа потоков Python с GIL и без него, загрузка ядер процессора и сравнение времени выполнения программ с разным количеством потоков.

Что находится в папке:

spin.py — программа с четырьмя потоками.
threads.py — сравнение времени работы 1, 2 и 4 потоков.
import threading.py — проверка потоков с ожиданием.
screen — 4 скриншота с выполненными заданиями (заменить заглушки своими снимками).

Python без GIL устанавливается командой uv python install 3.14 3.14t.

Проверка

GitHub Actions проверяет, что все заглушки заменены настоящими скриншотами.

Результат находится во вкладке Actions → Проверки.
