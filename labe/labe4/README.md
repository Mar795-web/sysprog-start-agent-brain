ЛР 4. Дерево процессов

В лабораторной работе изучается структура процессов системы: их родители и дочерние процессы, способы определения родителя через терминал и поведение процессов после завершения родительского процесса.

Что нужно сдать:
report.md - 
screen — 7 скриншотов с выполненными заданиями (заменить заглушки своими снимками).

Программировать ничего не нужно, все команды вводятся в терминале.

Проверка

GitHub Actions проверяет, что все заглушки заменены настоящими скриншотами.

Результат находится во вкладке Actions → Проверки.
